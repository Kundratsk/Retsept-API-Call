# 🍽️ Recipe App

See on Reacti rakendus, kus saab:
- otsida retsepte
- lisada lemmikutesse
- planeerida sööke (meal planner)
- vaadata retsepti detaile

---

# Kõigepealt tee .env kaust recipe_api_call kausta sisse
sinna .env kausta pane "Saadan meilile"

###  Installi dependencyd ja käivita projekt
npm install
npm install bootstrap
npm run dev

### Äpi kirjeldus

# Otsing
Kasutaja saab otsida retsepte API-st
Tulemused salvestatakse localStorage-sse

# Lemmikud

Lisa / eemalda retsepte lemmikutesse
Andmed salvestatakse localStorage-sse

# Meal Planner

Lisa retsepte hommiku, lõuna, õhtu või snäki alla

# Retsepti detailvaade

Näitab koostisosi
Näitab juhiseid
Näitab toitumisinfot (makrod)

### Projekt kasutab Spoonacular API-t retseptide andmete saamiseks.

API dokumentatsioon:
https://spoonacular.com/food-api/docs
